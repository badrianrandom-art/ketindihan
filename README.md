# Sleep Paralysis — 2D Storytelling (Remotion)

Project starter video animasi 2D flat, terinspirasi dari referensi video yang kamu kirim:
- Format vertikal 1080x1920, 30 fps, durasi 30 detik
- Palet warna navy, ungu, abu-abu, aksen emas
- Kamar, karakter, notifikasi, dan ilustrasi otak dibuat dengan elemen vector/CSS langsung di Remotion
- Tidak membutuhkan API AI atau layanan berbayar

## Menjalankan di GitHub Codespaces

```bash
npm install
npm run start
```

Pilih composition `SleepParalysis` di Remotion Studio.

## Render MP4

```bash
npm run render
```

Hasil: `out/sleep-paralysis.mp4`

## Catatan
Ini starter visual. Voice-over, musik, dan sound effects belum dimasukkan agar kamu bisa memilih audio sendiri. Semua scene dan teks dapat diedit di `src/SleepParalysis.tsx`.
